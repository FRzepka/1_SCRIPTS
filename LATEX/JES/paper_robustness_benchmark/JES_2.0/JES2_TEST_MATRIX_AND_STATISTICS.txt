2. FIXED WITHIN-TRAJECTORY STATE TESTS
  Every model run reports MAE, RMSE, bias, P95 error, sample count, and coverage
  fraction separately for the following protocol-defined states. The strata use the
  uncorrupted reference operating state, not the disturbed sensor value.

  SOH STATE
    Fresh:    SOH >= 0.90
    Mid-life: 0.80 <= SOH < 0.90
    Aged:     SOH < 0.80

  INSTANTANEOUS LOAD
    Low:      |C-rate| < 0.5
    Medium:   0.5 <= |C-rate| < 1.5
    High:     |C-rate| >= 1.5

  TEMPERATURE STATE
    Nominal:  T <= 30 degC
    Elevated: 30 < T <= 35 degC
    Hot:      T > 35 degC

  SOC STATE
    Low:      SOC < 0.20
    Middle:   0.20 <= SOC <= 0.80
    High:     SOC > 0.80

3. DISTURBANCE TESTS TO RUN ON ALL SIX CELLS
  Baseline.
  Current noise: sigma = 0.02 A and 0.10 A.
  Voltage noise: sigma = 0.01 V.
  Temperature noise: sigma = 1.0 degC.
  Current gain error: the final benchmark build uses matched +/-0.5%, +/-1.5%,
  and +/-3.0% sign pairs. Figure 05 reports the adverse direction of each matched
  pair so signed compensation with baseline error is not interpreted as
  robustness.
  Voltage offset: +0.02 V.
  Temperature offset: +3 degC.
  ADC quantization.
  Initial SOC-equivalent mismatch: -10% for DM/HDM coulomb-counting state,
  HECM EKF SOC state, and DD via Q_c offset of -0.10 times nominal capacity.
  The estimator difference at the first commonly scored sample is reported for
  every model. Observation starts 0.562 h after intervention. Endpoints already
  satisfied there are left-censored and recorded as conservative upper bounds.
  Periodic missing samples: every 50th sample.
  Random missing samples: 2%.
  Timing jitter: +/-0.1 s, +/-0.5 s, and +/-0.9 s.
  Burst dropout: the eligible 1 h interval with maximum absolute net charge,
  selected with at least 12 h of pre-gap and 24 h of post-gap context.
  Voltage spikes: +/-0.20 V every 1000 samples with randomized sign.

  Gaussian sensor-noise scenarios use 10 deterministic seeds per window. Random
  missing-sample, jitter, and spike scenarios use 5 seeds. Deterministic scenarios
  run once. Primary SOH-aware results use the shared causal LSTM-SOH.
  Selected scenarios additionally run with ideal reference SOH as a paired
  explanatory ablation.

4. NEW CROSS-FACTOR ANALYSES
  Baseline estimator accuracy by SOH state.
  Baseline estimator accuracy by instantaneous load, temperature, and SOC state.
  Cell-load class x SOH-state interaction for each estimator.
  Disturbance delta-MAE by SOH state for current noise, temperature noise, and
  one-hour dropout.
  Paired LSTM-SOH versus reference-SOH error propagation by cell and scenario.
  SOH publication cadence at 1 h, 6 h, and 24 h under baseline conditions.
  HECM lookup-table sensitivity: nominal lookup, joint resistance scaling by
  +/-10%, joint time-constant scaling by +/-10%, and OCV shifts by +/-10 mV.
  Each condition is crossed with 20 measurement and signal-integrity subcases,
  the paired initialization intervention, original seeds, all 16 frozen windows,
  lookup-matched baselines, and paired initialization
  recovery with a separately matched recovery baseline. The resulting 8,960-run analysis is reported separately and does
  not enter the cross-model robustness score. It evaluates the fixed HECM under
  local one-at-a-time lookup perturbations rather than combined parameter errors
  or alternative observer structures.
  Current-gain mechanism diagnostics: adverse signed pair across five common
  three-state cells; identical C29 trace replayed at SOH 0.962, 0.897, and 0.831;
  natural versus disabled full-charge reset; and one continuous 1,344 h C29
  trajectory with active CV resets. These tests separate SOH effects from signed
  charge history and from independent-window initialization.

5. STATISTICAL ANALYSIS
  Independent statistical unit: holdout cell, not individual time sample.
  Common evaluation mask: source samples 2023 onward for every estimator. This
  gives 84,377 matched points per 24 h run and 170,777 per 48 h dropout run.
  Frozen SOH windows are averaged inside each cell/seed before inferential
  comparison; random seeds are then nested inside each cell.
  Point estimate: equal-weight cell-macro mean, so C27's longer trajectory does
  not dominate C13's shorter trajectory.
  Uncertainty: hierarchical bootstrap with random seeds nested inside cells;
  report 95% confidence intervals.
  Scenario test: paired cell-level delta-MAE versus the cell-matched baseline.
  Model ranking test: paired cell-level differences for every estimator pair.
  Exact inference: two-sided paired sign-flip test on cell-level differences.
  Multiplicity: Holm correction across the reported family of tests.
  Effect size: paired standardized mean difference dz, plus raw mean/median
  difference and bootstrap CI.
  Reporting: always include n_cells and the minimum/maximum seeds per cell.

7. LIMITATIONS THAT MUST REMAIN EXPLICIT
  Load class is a descriptive dataset stratum, not a different battery chemistry
  or a randomized treatment.
  Group sizes are low n=2, middle n=3, and high n=1. Interaction panels show
  these counts. The C29 high-load row is an exploratory single-cell case and
  cannot support population-level high-load claims.
  C27 contains no mid-life/aged SOH and no hot-temperature interval. Missing cells
  in a state are reported as N/A, never imputed.
  The same trajectory contributes to several within-cell states; time samples are
  not treated as independent replicates.
  Results remain limited to the available LFP dataset and its operating envelope.
  The offline reconstructed SOC target is the common dataset ground truth used
  for every reported SOC error.
  The HECM surfaces originate from the training/validation development pool and
  exclude the six holdout cells. The HPPC identification records and fitted
  surfaces remain required release artifacts.
  Raw six-cell hardware summaries and a clean tagged firmware rebuild must be
  archived before resubmission.
