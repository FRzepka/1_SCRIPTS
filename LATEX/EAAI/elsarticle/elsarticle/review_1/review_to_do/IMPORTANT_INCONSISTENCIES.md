# Important consistency audit

## SOH filter

The result source `benchmark_results.npz` was generated by code that applies
first-point scaling, an EMA with `alpha=0.02`, and a symmetric relative/absolute
step limiter. The manuscript describes another filter (`alpha=1e-6`, downward-only
limit `2e-8`). At 1 Hz, the theoretical EMA time constants are approximately:

| Definition | Time constant | 50% response | 90% response |
|---|---:|---:|---:|
| Saved benchmark code, alpha=0.02 | 49.5 s | 34.3 s | 114.0 s |
| Manuscript text, alpha=1e-6 | 11.57 days | 8.02 days | 26.65 days |

The two definitions are not interchangeable. The local recalculation also shows
different SOH errors, so method, figures, tables, abstract, and conclusions must all
refer to one verified pipeline.

The original benchmark saved the Quantized SOH output only after calibration and
filtering. The missing raw trajectory has now been generated by locally executing
the exported Quantized C model. Base and Pruned were also re-executed in the same
Windows environment, giving an internally consistent three-model raw-to-filter
comparison over 14,496,990 samples.

This local run must remain clearly separated from the archived Linux benchmark.
The first 10,000 Quantized samples reproduce the stored filtered output closely
(MAE difference about `7.5e-6` SOH), but the complete recurrent sequence does not
remain numerically identical (MAE difference about `0.019` SOH). The local figures
therefore support a filter/compression interaction analysis, not an unlabelled
replacement of the originally reported metrics.

## Energy

The benchmark summary uses `energy = inference time * 0.5 W`. It therefore includes
the timing consequences of code and memory access only indirectly, while assuming a
constant power. It cannot determine whether flash access dominates consumption.
Report this as an estimated energy proxy unless raw external power traces are found.

The manuscript currently contains adjacent duplicate KPI paragraphs with conflicting
microjoule/millijoule wording. For example, 1.40 ms times 0.5 W equals 0.70 mJ, or
700 uJ. Both numerical forms are equivalent, but the table header and prose must use
one unit consistently.

## Quantization and memory

The C headers and kernels show INT8 recurrent matrices with FP32 per-row scales.
Biases, activations, hidden/cell states, and MLP tensors remain FP32. Thus the method
is weight-only mixed-precision quantization, not full integer inference. Any sentence
claiming quantized activations or a fourfold reduction of all model memory is too
broad.

## Pruning interpretation

The available exported models show 64 to 45 SOC units and 128 to 90 SOH units. The
weight distributions and L2 saliency can justify the selected structured criterion.
They cannot establish that the small SOC MAE improvement was caused by regularization,
because no repeated seeds or matched ablation are available.

## Fault and robustness scope

The new fault CSVs cover held outputs and one-bit corruption of an FP32 output value.
They do not exercise the LSTM after corrupting recurrent state, weights, activations,
input sensors, sampling intervals, or communication packets. Label them as limited
software sensitivity checks, not embedded fault-injection validation.
